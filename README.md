Static site (HTML/CSS/JS, no build step). Wedding: 03 Dec 2026, 09:00 AM, Ram Mandir, Battisputali, Kathmandu.

## Deploy on GitHub Pages
1. Create a new GitHub repository (e.g. `wedding`), public.
2. Upload everything in this folder (`index.html`, `images/`, `.nojekyll`, `README.md`) to the repo root.
3. Go to **Settings → Pages**. Under *Build and deployment* choose **Deploy from a branch**, branch **main**, folder **/ (root)**, then Save.
4. After ~1 minute your site is live at `https://<your-username>.github.io/<repo-name>/`.

## Deploy on Vercel / Netlify
Import the repo, framework preset **Other**, no build command, output directory `.`.
